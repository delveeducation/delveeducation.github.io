Plan de estudio

Contenido del curso

01

Fundamentos y Primer Script

Instala Python, configura tu entorno, explora Google Colab y crea tu primer programa con variables.

  • →Instalación de Python y entorno
  • →Google Colab y Jupyter
  • →Variables y tipos básicos
  • →Tu primer script
02

Tipos de Datos y Control de Flujo

Trabaja con números, cadenas y booleanos, y aprende a usar condicionales y bucles.

  • →Números, cadenas y booleanos
  • →Condicionales if/elif/else
  • →Bucles for y while
  • →Operadores lógicos
03

Estructuras de Datos

Aprende a usar listas, diccionarios, tuplas y sets para organizar y manipular datos eficientemente.

  • →Listas y operaciones
  • →Diccionarios y acceso por clave
  • →Tuplas y sets
  • →Iteración sobre estructuras
04

Funciones y Manejo de Errores

Define funciones, utiliza parámetros, maneja excepciones y explora funciones lambda.

  • →Definición de funciones
  • →Parámetros y retorno de valores
  • →Manejo de excepciones try/except
  • →Funciones lambda
05

Archivos y Librerías

Lee y escribe archivos, utiliza librerías estándar como os y sys, y explora numpy y pandas.

  • →Lectura y escritura de archivos
  • →Librerías os y sys
  • →Introducción a NumPy
  • →Introducción a Pandas
06

Programación Orientada a Objetos

Crea clases, objetos y métodos, e implementa herencia simple en Python.

  • →Clases y objetos
  • →Métodos y atributos
  • →Herencia simple
  • →Encapsulamiento
07

Python Intermedio

Descubre list comprehensions, generadores con yield y decoradores básicos para funciones.

  • →List comprehensions
  • →Generadores con yield
  • →Decoradores básicos
  • →Context managers
08

Aplicaciones Prácticas

Aplica Python en automatización de tareas, web scraping con BeautifulSoup y gráficos con matplotlib.

  • →Automatización de tareas
  • →Web scraping con BeautifulSoup
  • →Visualización con matplotlib
  • →APIs y requests
09

Proyecto Final: Gestor de Notas

Integra todo lo aprendido creando un gestor de notas que lea datos desde CSV, procese estadísticas y genere gráficos.

  • →Lectura de CSV con pandas
  • →Procesamiento de estadísticas
  • →Generación de gráficos
  • →Entrega y presentación
